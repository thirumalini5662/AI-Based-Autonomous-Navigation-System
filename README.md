AI-Based Autonomous Navigation System

📌 Project Overview

The AI-Based Autonomous Navigation System is a Python-based virtual simulation that demonstrates how an autonomous agent can navigate through an environment while avoiding obstacles.

The project represents the environment as a 2D grid. Obstacles are placed in the environment, a start position and destination are defined, and the A* path-planning algorithm calculates a suitable collision-free route.

The virtual autonomous agent then follows the planned route toward the destination.

🧠 A* Path Planning

The project uses the A* algorithm to calculate a path between the starting point and the destination.

A* combines:

- Actual movement cost
- Estimated remaining distance
- A heuristic function

For this project, the Manhattan distance heuristic is used because the virtual agent moves through a four-directional grid.

🚀 Installation

Clone the repository and open the project folder in VS Code.

Create a virtual environment:

python -m venv .venv

Activate it on Windows:

.venv\Scripts\activate

Install the required libraries:

pip install -r requirements.txt

▶️ Run the Project

Run:

python run.py

The simulation displays:

- Black obstacles
- Start position
- Goal position
- Planned A* path
- Autonomous navigation agent

🧪 Run Tests

To test the path-planning module:

python -m unittest discover -s tests -v
