# Project Notes

## What this project demonstrates
A virtual autonomous agent moves from a start point to a destination through a 2D obstacle map.

## Main algorithm
A* path planning is used because it combines travelled cost and a heuristic estimate to efficiently find a route.

## Simulated components
- Environment/map
- Obstacles
- Start and goal
- Path planning
- Agent navigation
- Progress display
- Result visualization

## Not included yet
Real camera perception, YOLO inference, LiDAR, GPS/IMU, ROS, vehicle dynamics and real motors. These are future upgrades.
